단어장에 들어 있는 카드를 다운로드해요.

앞면·뒷면·읽는 법과 발음 언어를 CSV로 저장해요.

앞면, 뒷면, 읽는법 열을 인식해요. 예전의 '일본어 / 읽는 법 / 한국어 뜻' CSV도 사용할 수 있어요. 같은 카드를 다시 가져오면 중복될 수 있어요.

카드 CSV에는 카드 내용만 들어 있어요. 공부 기록은 📊 공부 기록·CSV에서 별도 내보낼 수 있고, 진행상황 복원은 JSON 백업을 사용하세요.

📊 회독별 공부 기록

완료한 회독의 시간·분류 차수·오답 선택 횟수를 기록해요. 진행 중인 회독도 내보낼 수 있어요.

이전 버전에서 저장된 누적 시간은 보존되지만, 과거 회독별 시간으로 나눌 수는 없어요. CSV는 분석용이며, 실제 진행 상태의 복원은 JSON 전체 백업을 사용하세요.

카드 관리

JLPT N1 · KANJI READING LAB

漢 한자 읽기 연구실

내 N1 단어장 DAY 01~10의 1,766개 항목에서 반복 등장하는 한자를 골랐어. 횟수는 이 자료 안의 등장 횟수이고, 표의 음독·훈독은 대표적인 읽기만 표시해. 교재에 없는 읽기도 포함되므로 실제 단어를 통해 확인해 줘.
① 한자 둘 이상의 단어음독이 자주 쓰여요. 行為(こうい), 行政(ぎょうせい)처럼 여러 음독이 있을 수 있어요.
② 한자 + 히라가나送り仮名가 붙으면 훈독을 먼저 생각해요. 調べる(しらべる)처럼요.
③ 섞이는 읽기手錠(てじょう)처럼 훈독+음독도 있어요. 무조건 한 가지 규칙으로 단정하지 않아요.
④ 예외도 단어째 암기읽기가 여러 개이거나 관용적으로 굳어진 말은 단어째 외우는 편이 정확해요.
